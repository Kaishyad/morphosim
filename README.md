# Morphosim
Simulation dissertation comparing Mk and NT models for Bayesian morphological phylogenetic inference.


## Project overview

This repository contains all R scripts, RevBayes inference scripts, and SLURM
batch scripts to:

1. Simulate morphological character matrices across a parameter grid.
2. Run Bayesian inference under twelve models.
3. Assess tree accuracy, MCMC convergence, and more diagnostics.

Simulation outputs (MCMC logs, tree files, result files) are stored in a companion
data repository: **the-matrix** which can be found at https://github.com/Kaishyad/the-matrix.
